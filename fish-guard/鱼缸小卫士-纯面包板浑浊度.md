# 鱼缸小卫士 · 纯面包板浑浊度检测（不用 Arduino）

> 用面包板 + 分立元件实现浑浊度“阈值报警”：水变浑 → 红灯亮、蜂鸣器响。  
> 适合 8 岁以上孩子在成人陪同下完成；全程 4.5–5V 电池或充电宝供电。  
> 与主文档《鱼缸小卫士-施工文档》互补：本文是纯模拟版，主文档是 Arduino 版。

---

## 1. 能做到什么、做不到什么

| 能力 | 纯面包板版 | 说明 |
|---|---|---|
| 水变浑报警 | ✅ | 阈值触发，亮红灯、响蜂鸣器 |
| 调节灵敏度 | ✅ | 电位器设定报警临界点 |
| 显示浑浊度数值 | ❌ | 需要单片机 |
| 记录趋势 / 数据 | ❌ | 需要 Arduino + 串口/存储 |
| 抗环境光干扰 | ⚠️ | 靠黑色遮光筒 + 阈值余量，见第 7 节 |
| 多级报警 / 迟滞 | 部分 | 比较器版可加迟滞，三极管版没有 |

**结论**：纯面包板做“哨兵”够用——发现水明显变浑就提醒你换水/检查过滤；但要显示数字、记录历史，还是得上 Arduino。

## 2. 原理（30 秒版）

透射式：一只 LED 常亮，光穿过水体照到对面的光敏电阻（LDR）。

- **清水**：光几乎全透过去 → LDR 阻值低。
- **浑水**：悬浮颗粒散射/挡住光 → LDR 阻值变高。

把 LDR 和一个固定电阻串成“分压器”，LDR 阻值变化就变成**电压变化**。再用比较器（或三极管）判断：电压超过设定阈值 → 报警。

```
[LED] ──光──▶ 水体 ──光──▶ [LDR]
           清水：光强 → LDR 阻值低 → 节点电压低
           浑水：光弱 → LDR 阻值高 → 节点电压高
```

> 和“魔法小夜灯”是同一颗光敏电阻在干活，只是光源从环境光换成了自己控制的 LED，方向相反。

## 3. 方案选择

| 方案 | 元件数 | 阈值干净度 | 适合 |
|---|---|---|---|

## 4. 方案 B：LM393 比较器版（推荐）

### 4.1 材料

| 部件 | 数量 | 备注 |
|---|---|---|
| LM393 双比较器 | 1 | DIP-8，只用一个比较器 |
| 光敏电阻 GL5528 | 1 | 接收端 |
| 白色或红色 LED（光源） | 1 | 亮度越稳定越好 |
| 红色 LED（报警） | 1 | 水变浑点亮 |
| 有源蜂鸣器 5V | 1 | 可选，加声音提醒 |
| NPN 三极管 S8050 | 1 | 缓冲驱动蜂鸣器/LED |
| 电阻 220Ω | 1 | 光源 LED 限流 |
| 电阻 330Ω | 1 | 报警 LED 限流 |
| 电阻 1kΩ | 1 | 三极管基极 |
| 电阻 10kΩ | 2 | 分压、输出上拉 |
| 电位器 10kΩ | 1 | 设定报警阈值 |
| 面包板 + 跳线 | 1 套 | |
| 3×AA 电池盒 + 电池 或 5V 充电宝 | 1 | 供电 |
| 黑色卡纸/黑胶带 | 适量 | 遮光筒 |

总价约 ¥10–25（不含电池盒和面包板）。

### 4.2 LM393 引脚（缺口/圆点朝上，逆时针数）

```
       ┌──────────┐
 OUT1 │1        8│ VCC
 IN1- │2        7│ OUT2
 IN1+ │3        6│ IN2-
 GND  │4        5│ IN2+
       └──────────┘
```

只用比较器 1：pin1 输出、pin2 反相输入(-)、pin3 同相输入(+)、pin4 地、pin8 电源。

### 4.3 接线图

```
电源：电池盒红线 ── 面包板 + 轨（记作 +V，4.5–5V）
      电池盒黑线 ── 面包板 ─ 轨（记作 GND）

① 光源（常亮，隔着水照 LDR）：
   +V ── 220Ω ── LED(光源)正极；LED负极 ── GND

② 传感分压：
   +V ── 10kΩ ── 节点S ── LDR ── GND
   （节点S 的电压 = 浑浊度的“读数”）

③ 比较器 LM393：
   pin8 ── +V
   pin4 ── GND
   pin3(IN1+) ── 节点S
   pin2(IN1-) ── 电位器中间脚
   电位器另外两端 ── +V 和 GND

④ 输出上拉：
   pin1(OUT1) ── 10kΩ ── +V

⑤ 报警驱动（NPN 缓冲）：
   pin1 ── 1kΩ ── S8050 基极
   S8050 发射极 ── GND
   S8050 集电极 ── 报警LED阴极(经330Ω) + 蜂鸣器负极
   报警LED阳极 ── +V；蜂鸣器正极 ── +V
```

### 4.4 工作逻辑

- **清水**：LDR 阻值低 → 节点S 电压低 → S < 阈值 → 比较器输出低 → NPN 截止 → 灯灭、不响。
- **浑水**：LDR 阻值高 → 节点S 电压升高 → S > 阈值 → 比较器输出高 → NPN 导通 → 灯亮、响。

阈值电位器决定“S 多高算浑水”。

## 5. 方案 A：三极管开关版（最简）

省掉 LM393，直接让分压节点驱动 NPN。

```
+V ── 电位器(10k) ── 节点S ── LDR ── GND
节点S ── S8050 基极
S8050 发射极 ── GND
S8050 集电极 ── 报警LED阴极(经330Ω) ── ... 报警LED阳极 ── +V
```

- 清水 LDR 低阻 → S 电压低 → 三极管截止 → 灯灭。
- 浑水 LDR 高阻 → S 电压升高 → 三极管导通 → 灯亮。

灵敏度靠电位器调“临界点”。缺点是导通是渐进的，灯会从暗到亮慢慢变，不像比较器那样干脆；适合孩子理解“分压 + 开关”概念。

## 6. 校准步骤（方案 B，家长量、孩子看）

1. 接好电路，开电源，确认**光源 LED 亮**。
2. 万用表电压档，红笔量**节点 S**（对 GND），黑笔接地。清水状态下记下这个值，比如 `1.8V`。
3. 红笔量**电位器中间脚**（IN-），记下当前值。
4. 调电位器，让 IN- 电压**略高于**清水时的 S。例：S=1.8V，把 IN- 调到 `2.2V`。此时 S < IN-，报警灯灭（安全状态）。
5. **验证**：往杯子里滴 1–2 滴牛奶并搅拌，看节点 S 是否升高（比如升到 `2.8V`）。超过 IN-（2.2V）后，报警灯亮、蜂鸣器响。
6. 换回清水，报警应熄灭（可逆）。

**灵敏度怎么定**：IN- 越接近清水 S，越灵敏（容易误报）；越接近浑水 S，越迟钝（容易漏报）。先取清水 S 和明显浑水 S 的**中间值**最稳，再按实际鱼缸情况微调。

## 7. 最大的坑：环境光

光敏电阻分不清“我的 LED 光”和“室内灯光”。室内灯、窗户光都会叠加上去，让读数漂、误报警。

**解决（按顺序）**：

1. **黑色遮光筒**：用黑卡纸卷成筒，把 LED 和 LDR 各自罩住，中间只留水体这一段，两端几乎密封。
2. **关掉直射灯**：把测试杯放在背光处，别让阳光/台灯直射。
3. **加大阈值余量**：IN- 离清水 S 远一点，容忍轻微环境光波动。
4. **终极方案**：换**红外 LED + 红外光电晶体管**，配合遮光，红外受可见光影响小得多；但需要重新标定，属于进阶。

纯模拟方案没有 Arduino 版那种“先测环境光、再测亮灯、相减”的补偿能力，所以**遮光做得好不好，直接决定这个报警器靠不靠谱**。

## 8. 局限与升级路径

| 局限 | 后果 | 何时该升级到 Arduino |
|---|---|---|
| 只有阈值，无数值 | 不知道“有多浑” | 想看数字/曲线时 |
| 无环境光补偿 | 读数受室内光影响 | 遮光救不了、经常误报时 |
| 无迟滞（三极管版） | 临界点附近闪烁 | 想稳定报警时 |
| 无历史记录 | 不知道水是突然变浑还是慢慢变浑 | 想记录趋势时 |

升级路径：本电路的光学部分（LED + 光敏电阻 + 遮光筒）**原样保留**，只把“节点 S 电压”从比较器输入改成接 Arduino 的 `A1` 引脚，就能用主文档《鱼缸小卫士-施工文档》里的代码读出数字、做环境光补偿和趋势记录。所以先做纯面包板版不白做——它就是你以后 Arduino 版的光学前端。

## 9. 安全

1. 全程 4.5–5V 电池或充电宝供电，**不接市电**。
2. LED 和光敏电阻**不接触水**，隔着玻璃测；只有想测“水体”时才需要让光穿过，元件本身在外侧。
3. **绝不在鱼缸里加牛奶/面粉做测试**，只在单独杯子里做。
4. 光源 LED 常亮会持续耗电，测完关掉电池盒开关；孩子不玩时由成人断电。
5. 蜂鸣器音量适中，别吓到鱼。
