# 鱼缸小卫士：淡水鱼缸 Arduino 水质监测与报警器

> 亲子施工文档 · 默认热带淡水鱼 24–28°C · 5V 安全供电  
> 适合 8 岁以上孩子在成人陪同下参与；接线、代码和涉水部分由成人主导。  
> 配套程序：`arduino/fish_guard/fish_guard.ino`（主程序）与 `arduino/turbidity_test/turbidity_test.ino`（浑浊度独立测试）

---

## 0. 一页速览

**它能做什么**

- DS18B20 防水探头测水温，OLED 显示到 0.1°C，超范围声光报警。
- 浮球开关检测水位过低。
- 脉冲式漏水探针检测鱼缸下方托盘积水。
- LED + 光敏电阻隔着玻璃测浑浊趋势（可选安装）。
- 按键翻页，长按静音 10 分钟；漏水和探头故障不受静音影响。
- 串口每 10 秒输出一行 CSV，孩子可以收集“水质日报”。

**它不做什么**

- 不测 pH、氨氮、亚硝酸盐、硝酸盐——这些用试剂盒。
- 不控制加热棒、水泵、灯或自动换水设备，只做监测和报警。
- 不是实验室仪表；温度精度约 ±0.5°C，浑浊度只做趋势判断。

**时间与预算**

- 一个周末可以完成：周六搭建和测试，周日校准、装盒和上缸观察。
- 材料约 ¥80–150，不含万用表、玻璃温度计和充电宝。

**绝对安全底线**

- 只使用 5V；推荐充电宝供电，若用适配器必须配漏电保护。
- 只有密封的 DS18B20 探头和浮球开关可以入水；LED、光敏电阻、漏水探针全部在缸外。
- 绝不把裸线、铜丝、电极放进鱼缸；绝不用 Arduino 控制 220V 或加热棒。
- 电子盒放在鱼缸上方或旁边，不能放进潮湿的缸盖里，所有线留“滴水弯”。

## 1. 项目目标与边界

| 指标 | 本设备能否监测 | 说明 |
|---|---|---|
| 水温 | ✅ 连续 | DS18B20 密封探头，最能提前发现加热棒故障 |
| 水位 | ✅ 连续 | 浮球开关，防止蒸发或换水后忘记补水 |
| 漏水 | ✅ 连续 | 缸下托盘双探针，及时发现渗漏 |
| 浑浊度 | ⚠️ 趋势 | 光学测量，受玻璃藻膜、气泡、环境光影响，需定期校准 |
| 过滤是否在转 | 可选升级 | 需要振动或水流传感器 |
| pH | ❌ | 电极需校准液、保存液，探头娇气；用滴剂/试纸 |
| 氨/亚硝酸盐 | ❌ | 目前没有便宜可靠的连续传感器；必须用试剂 |
| TDS/电导率 | 不建议 | 淡水缸里这个数字对鱼健康意义有限 |

> 记住：这台设备是“温度、水位、漏水和浑浊趋势的哨兵”；真正的化学水质检测仍然靠试剂盒和定期换水。

## 2. 系统结构

```
                       5V USB（充电宝 / 带漏保的适配器）
                                  │
                    ┌─────────────┴─────────────┐
                    │       Arduino Nano        │
                    └──┬────┬────┬────┬────┬────┘
     I2C A4/A5 ────────┘    │    │    │    │
                           │    │    │    └── D9 ─ 1k ─ S8050 ─ 有源蜂鸣器 ─ 5V
     D2 ─ DS18B20 数据线（4.7k 上拉到 5V）     │
     D3 ─ 按键 ─ GND                          │
     D4 ─ 浮球开关 ─ GND                      │
     D7 ─ 220Ω ─ 浑浊度 LED ─┐                │
     A1 ─ 光敏电阻 ───────────┘ 黑色遮光筒夹在玻璃上
     D8 ─ 漏水螺丝 A；螺丝 B ─ A0；A0 ─ 10k ─ GND
```

测温探头、浮球可以入水；其余传感器都在鱼缸外。浑浊度的 LED 和光敏电阻隔着玻璃测量，不接触水。

## 4. 接线表

| 模块/元件 | 连接方式 |
|---|---|
| DS18B20 红线 | 5V |
| DS18B20 黑线 | GND |
| DS18B20 黄线 | D2；D2 与 5V 之间接 4.7kΩ |
| OLED VCC / GND | 5V / GND |
| OLED SDA / SCL | A4 / A5 |
| 按键 | 一端 D3，另一端 GND（使用内部上拉，按下为低） |
| 浮球开关 | 一端 D4，另一端 GND；水位过低时应闭合 |
| 浑浊度 LED | D7 → 220Ω → LED 正极；LED 负极 → GND |
| 光敏电阻 | 5V → 光敏电阻 → A1；A1 → 10kΩ → GND |
| 漏水探针 | D8 → 螺丝 A；螺丝 B → A0；A0 → 10kΩ → GND |
| 蜂鸣器（裸） | D9 → 1kΩ → S8050 基极；发射极 GND；集电极 → 蜂鸣器负极；蜂鸣器正极 → 5V |
| 蜂鸣器（模块） | VCC 5V、GND、信号 D9；注意模块是高电平还是低电平触发 |

**接线的三个提醒**

1. OLED 的 SDA/SCL 接 A4/A5，不要接成 A2/A3；屏幕不亮时先查这里和 I2C 地址。
2. DS18B20 的 4.7kΩ 上拉电阻不能省；没有它读数会失败。
3. 漏水探针的 D8 只在测量时短暂通电，不要把它接到持续 5V，否则探针会更快腐蚀。

### 4.1 浑浊度光学安装

透射式（默认）：

```
鱼缸玻璃
[LED] →→→→ 水体 →→→→ [LDR]
```

清澈时到达光敏电阻的光多，浑浊时变少；代码里 `TURB_INVERT = false`。

散射式（大缸或透射信号太弱时）：

```
[LED] ↘
       水体颗粒 → [LDR]
```

LED 和光敏电阻在同一侧，约 45° 角度，中间用黑色隔板挡住直射光；浑浊时散射到光敏电阻的光变多。代码里把 `TURB_INVERT` 改成 `true`，并重新校准基线。

两种方式都必须用黑色卡纸/黑胶带做遮光筒，挡住室内灯光。LED 每次只亮约 60ms、每 5 秒一次，减少对鱼的影响。

## 5. Arduino 程序

### 5.1 安装库

在 Arduino IDE 的“库管理器”中安装：

- `OneWire`
- `DallasTemperature`
- `Adafruit SSD1306`
- `Adafruit GFX Library`

### 5.2 板卡设置

- 板卡：Arduino Nano
- 处理器：ATmega328P（克隆版上传失败时选 ATmega328P (Old Bootloader)）
- 端口：选择对应 USB 串口

### 5.3 程序行为

- 第 1 页：大号水温、状态文字和一条小鱼图标。
- 第 2 页：本次开机以来的最低/最高温、阈值、浑浊度百分比、漏水原始值、浮球状态。
- 第 3 页：校准提示和当前浑浊度基线。
- 短按按键翻页；长按 2 秒静音/取消静音 10 分钟。
- 水位/漏水报警和探头故障报警不受静音影响。
- 串口 9600 波特率，每 10 秒输出一行 CSV。

### 5.4 完整代码

```cpp
/*
  鱼缸小卫士 —— 淡水鱼缸 Arduino 水质监测与报警器
  硬件：Arduino Nano / DS18B20 / 0.96" I2C OLED / 有源蜂鸣器 /
        浮球开关 / 漏水探针 / LED + 光敏电阻
  供电：5V USB（充电宝或带漏保的适配器）
  注意：只有密封的 DS18B20 和浮球可以入水，其余传感器都在缸外。
*/

#include <OneWire.h>
#include <DallasTemperature.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <EEPROM.h>

// ---------------- 引脚 ----------------
const uint8_t PIN_DS18B20  = 2;
const uint8_t PIN_BUTTON   = 3;
const uint8_t PIN_FLOAT    = 4;
const uint8_t PIN_TURB_LED = 7;
const uint8_t PIN_LEAK_PWR = 8;
const uint8_t PIN_BUZZER   = 9;
const uint8_t PIN_LEAK     = A0;
const uint8_t PIN_LDR      = A1;

// ---------------- 参数 ----------------
const float TEMP_LOW  = 24.0;    // 按鱼种修改
const float TEMP_HIGH = 28.0;
const float TEMP_HYST = 0.3;     // 回差，避免阈值附近闪烁
const float TEMP_OFFSET = 0.0;   // 和玻璃温度计对比后微调
const unsigned long TEMP_CONFIRM_MS = 60000UL;

const int LEAK_THRESHOLD = 300;  // 0-1023，用湿纸巾实测后调整
const unsigned long WATER_CONFIRM_MS = 2000UL;

const bool USE_TURBIDITY = true; // 没装光学头就改成 false
const bool TURB_INVERT = false;  // 散射式改 true
const int TURB_ALARM_PCT = 20;   // 比干净水少 20% 视为浑浊
const unsigned long TURB_CONFIRM_MS = 600000UL; // 持续 10 分钟才报警

const unsigned long MUTE_MS = 600000UL; // 静音 10 分钟

// ---------------- 对象 ----------------
OneWire oneWire(PIN_DS18B20);
DallasTemperature sensors(&oneWire);
Adafruit_SSD1306 display(128, 64, &Wire, -1);

struct Latch { bool active; unsigned long since; };
Latch cold = {false, 0};
Latch hot = {false, 0};
Latch water = {false, 0};
Latch turbid = {false, 0};
Latch sensorFault = {false, 0};

float tempC = NAN;
float tempMin = 99.0;
float tempMax = -99.0;
bool tempValid = false;
unsigned long tempReqAt = 0;

int baseline = 500;      // 干净水的浑浊度信号，存 EEPROM
int turbSignal = 0;
int cloudPct = 0;
int leakValue = 0;
bool floatClosed = false;

unsigned long mutedUntil = 0;
uint8_t page = 0;

unsigned long lastTurb = 0;
unsigned long lastLeak = 0;
unsigned long lastSerial = 0;
unsigned long lastDisplay = 0;

// ---------------- 工具函数 ----------------
int readAvg(uint8_t pin, uint8_t n) {
  long sum = 0;
  for (uint8_t i = 0; i < n; i++) sum += analogRead(pin);
  return sum / n;
}

int measureTurbiditySignal() {
  digitalWrite(PIN_TURB_LED, LOW);
  delay(30);
  int ambient = readAvg(PIN_LDR, 8);
  digitalWrite(PIN_TURB_LED, HIGH);
  delay(60);
  int lit = readAvg(PIN_LDR, 8);
  digitalWrite(PIN_TURB_LED, LOW);
  int s = lit - ambient;
  return (s < 0) ? 0 : s;
}

int readLeak() {
  digitalWrite(PIN_LEAK_PWR, HIGH);
  delay(5);
  int v = readAvg(PIN_LEAK, 4);
  digitalWrite(PIN_LEAK_PWR, LOW);
  return v;
}

void updateLatch(Latch &l, bool cond, unsigned long confirmMs, unsigned long now) {
  if (!cond) {
    l.active = false;
    l.since = 0;
    return;
  }
  if (l.active) return;
  if (l.since == 0) l.since = now;
  if (now - l.since >= confirmMs) l.active = true;
}

void driveBuzzer(unsigned long now) {
  unsigned long period = 0, on = 0;

  // 漏水和传感器故障不受静音影响
  if (water.active) {
    period = 400; on = 200;
  } else if (sensorFault.active) {
    period = 1000; on = 100;
  } else if (now >= mutedUntil) {
    if (cold.active || hot.active) {
      period = 1500; on = 300;
    } else if (turbid.active) {
      period = 5000; on = 100;
    }
  }

  if (period == 0) digitalWrite(PIN_BUZZER, LOW);
  else digitalWrite(PIN_BUZZER, (now % period) < on ? HIGH : LOW);
}

void handleButton(unsigned long now) {
  static bool lastRaw = false;
  static bool stable = false;
  static unsigned long rawChanged = 0;
  static unsigned long pressStart = 0;

  bool raw = (digitalRead(PIN_BUTTON) == LOW);
  if (raw != lastRaw) {
    lastRaw = raw;
    rawChanged = now;
  }
  if (now - rawChanged >= 20 && raw != stable) {
    stable = raw;
    if (stable) {
      pressStart = now;
    } else {
      unsigned long held = now - pressStart;
      if (held >= 1500) {
        if (mutedUntil > now) mutedUntil = 0;
        else mutedUntil = now + MUTE_MS;
      } else if (held >= 50) {
        page = (page + 1) % 3;
      }
    }
  }
}

void drawFish(int x, int y, bool happy) {
  display.drawCircle(x, y, 7, SSD1306_WHITE);
  display.drawTriangle(x + 7, y, x + 13, y - 4, x + 13, y + 4, SSD1306_WHITE);
  display.drawPixel(x - 2, y - 2, SSD1306_WHITE);
  if (happy) display.drawLine(x - 3, y + 2, x + 1, y + 3, SSD1306_WHITE);
  else       display.drawLine(x - 3, y + 4, x + 1, y + 1, SSD1306_WHITE);
}

void drawScreen() {
  display.clearDisplay();
  display.setTextColor(SSD1306_WHITE);
  display.setTextSize(1);
  display.setCursor(0, 0);
  display.print("FISH GUARD");
  if (millis() < mutedUntil) {
    display.setCursor(92, 0);
    display.print("MUTE");
  }

  if (page == 0) {
    display.setTextSize(3);
    display.setCursor(0, 14);
    if (tempValid) {
      display.print(tempC, 1);
      display.print("C");
    } else {
      display.print("--.-");
    }

    display.setTextSize(1);
    display.setCursor(0, 52);
    bool anyBad = water.active || sensorFault.active || cold.active ||
                  hot.active || turbid.active;
    if (water.active)            display.print("WATER ALARM");
    else if (sensorFault.active) display.print("SENSOR ERROR");
    else if (cold.active)        display.print("TOO COLD");
    else if (hot.active)         display.print("TOO HOT");
    else if (turbid.active)      display.print("WATER CLOUDY");
    else                         display.print("ALL OK");

    drawFish(104, 26, !anyBad);

  } else if (page == 1) {
    display.setCursor(0, 12);
    display.print("MIN "); display.print(tempMin, 1);
    display.print(" MAX "); display.println(tempMax, 1);
    display.print("RANGE "); display.print(TEMP_LOW, 1);
    display.print("-"); display.print(TEMP_HIGH, 1); display.println("C");
    display.print("CLOUD "); display.print(cloudPct); display.println("%");
    display.print("WATER "); display.println(water.active ? "ALARM" : "OK");
    display.print("LEAK "); display.print(leakValue);
    display.print(" FLOAT "); display.println(floatClosed ? 1 : 0);
    display.print("TURB "); display.println(turbSignal);

  } else {
    display.setCursor(0, 12);
    display.println("Calibrate baseline:");
    display.println("clean glass, normal");
    display.println("light, hold button");
    display.println("3s while powering on.");
    display.println();
    display.print("Baseline: "); display.println(baseline);
    display.print("Hold 2s: mute");
  }
  display.display();
}

// ---------------- setup ----------------
void setup() {
  pinMode(PIN_BUTTON, INPUT_PULLUP);
  pinMode(PIN_FLOAT, INPUT_PULLUP);
  pinMode(PIN_TURB_LED, OUTPUT);
  pinMode(PIN_LEAK_PWR, OUTPUT);
  pinMode(PIN_BUZZER, OUTPUT);
  digitalWrite(PIN_TURB_LED, LOW);
  digitalWrite(PIN_LEAK_PWR, LOW);
  digitalWrite(PIN_BUZZER, LOW);

  Serial.begin(9600);
  Serial.println(F("sec,tempC,cloudPct,leak,floatClosed,cold,hot,water,turbid"));

  Wire.begin();
  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    display.begin(SSD1306_SWITCHCAPVCC, 0x3D); // 部分模块地址是 0x3D
  }
  display.clearDisplay();
  display.setTextColor(SSD1306_WHITE);
  display.setTextSize(1);
  display.setCursor(0, 0);
  display.println("FISH GUARD booting");
  display.display();

  sensors.begin();
  sensors.setResolution(11); // 0.125°C，约 375ms
  sensors.setWaitForConversion(false);
  sensors.requestTemperatures();
  tempReqAt = millis();

  EEPROM.get(0, baseline);
  if (baseline < 50 || baseline > 1023) baseline = 500;
  Serial.print(F("baseline="));
  Serial.println(baseline);

  // 上电时按住按键 3 秒：把当前干净水信号存为浑浊度基线
  if (USE_TURBIDITY && digitalRead(PIN_BUTTON) == LOW) {
    display.setCursor(0, 16);
    display.println("Hold for CAL...");
    display.display();

    unsigned long t0 = millis();
    while (digitalRead(PIN_BUTTON) == LOW && millis() - t0 < 3000) delay(10);

    if (digitalRead(PIN_BUTTON) == LOW) {
      int s = 0;
      for (int i = 0; i < 3; i++) s += measureTurbiditySignal();
      s /= 3;
      Serial.print(F("CAL signal="));
      Serial.println(s);

      display.clearDisplay();
      display.setCursor(0, 0);
      if (s > 50) {
        baseline = s;
        EEPROM.put(0, baseline);
        display.println("CAL saved");
      } else {
        display.println("CAL too dark!");
      }
      display.print("Baseline: ");
      display.println(baseline);
      display.display();
      delay(1200);
    }
    while (digitalRead(PIN_BUTTON) == LOW) delay(10);
  }

  // 吞掉上电时残留的按键动作，避免误翻页
  while (digitalRead(PIN_BUTTON) == LOW) delay(10);
  display.clearDisplay();
}

// ---------------- loop ----------------
void loop() {
  unsigned long now = millis();

  handleButton(now);

  // 温度：非阻塞读取
  if (now - tempReqAt >= 500) {
    float t = sensors.getTempCByIndex(0);
    sensors.requestTemperatures();
    tempReqAt = now;

    if (t > -50.0 && t < 80.0) {
      tempC = t + TEMP_OFFSET;
      tempValid = true;
      if (tempC < tempMin) tempMin = tempC;
      if (tempC > tempMax) tempMax = tempC;
    } else {
      tempValid = false;
    }
  }

  // 漏水：每 500ms 通电测一次
  if (now - lastLeak >= 500) {
    lastLeak = now;
    leakValue = readLeak();
  }
  floatClosed = (digitalRead(PIN_FLOAT) == LOW);

  // 浑浊度：每 5 秒测一次
  if (USE_TURBIDITY && now - lastTurb >= 5000) {
    lastTurb = now;
    int s = measureTurbiditySignal();
    if (turbSignal == 0) turbSignal = s;
    else turbSignal = (turbSignal * 3 + s) / 4; // 平滑

    if (baseline > 0) {
      int pct = TURB_INVERT
        ? (turbSignal - baseline) * 100 / baseline
        : (baseline - turbSignal) * 100 / baseline;
      cloudPct = constrain(pct, 0, 100);
    } else {
      cloudPct = 0;
    }
  }

  // 报警逻辑
  bool coldCond = tempValid && (tempC < TEMP_LOW ||
                  (cold.active && tempC < TEMP_LOW + TEMP_HYST));
  bool hotCond  = tempValid && (tempC > TEMP_HIGH ||
                  (hot.active && tempC > TEMP_HIGH - TEMP_HYST));
  updateLatch(cold, coldCond, TEMP_CONFIRM_MS, now);
  updateLatch(hot, hotCond, TEMP_CONFIRM_MS, now);

  bool waterCond = floatClosed || (leakValue > LEAK_THRESHOLD);
  updateLatch(water, waterCond, WATER_CONFIRM_MS, now);

  updateLatch(sensorFault, !tempValid, 60000UL, now);

  bool turbidCond = USE_TURBIDITY && (cloudPct > TURB_ALARM_PCT);
  updateLatch(turbid, turbidCond, TURB_CONFIRM_MS, now);

  driveBuzzer(now);

  if (now - lastDisplay >= 300) {
    lastDisplay = now;
    drawScreen();
  }

  if (now - lastSerial >= 10000) {
    lastSerial = now;
    float logTemp = tempValid ? tempC : -999.0;
    Serial.print(now / 1000); Serial.print(',');
    Serial.print(logTemp, 1); Serial.print(',');
    Serial.print(cloudPct);   Serial.print(',');
    Serial.print(leakValue);  Serial.print(',');
    Serial.print(floatClosed ? 1 : 0); Serial.print(',');
    Serial.print(cold.active); Serial.print(',');
    Serial.print(hot.active);  Serial.print(',');
    Serial.print(water.active); Serial.print(',');
    Serial.println(turbid.active);
  }
}
```

## 6. 参数速查与校准

### 6.1 程序参数

| 参数 | 默认值 | 作用 |
|---|---|---|
| `TEMP_LOW` / `TEMP_HIGH` | 24.0 / 28.0°C | 水温报警窗口，按鱼种修改 |
| `TEMP_OFFSET` | 0.0°C | 与玻璃温度计对比后的修正值 |
| `TEMP_HYST` | 0.3°C | 回差，防止阈值附近反复报警 |
| `TEMP_CONFIRM_MS` | 60000ms | 超温持续 1 分钟才报警 |
| `LEAK_THRESHOLD` | 300 | 漏水模拟量阈值，湿纸巾实测后调整 |
| `WATER_CONFIRM_MS` | 2000ms | 水位/漏水持续 2 秒才报警 |
| `TURB_ALARM_PCT` | 20% | 浑浊度比基线低/高 20% 视为异常 |
| `TURB_CONFIRM_MS` | 600000ms | 浑浊持续 10 分钟才报警 |
| `MUTE_MS` | 600000ms | 长按静音 10 分钟 |

### 6.2 淡水鱼温度窗口参考

| 饲养对象 | 参考窗口 | 备注 |
|---|---|---|
| 热带混养鱼（灯鱼、孔雀等） | 24–28°C | 默认值；以实际鱼种资料为准 |
| 金鱼、白云金丝 | 18–24°C | 冷水鱼普遍更耐低温 |
| 斗鱼 | 25–28°C | 需要稳定水温 |
| 不确定时 | 当前实测水温 ±2°C | 先观察，再按鱼的状态调整 |

> 温度窗口应该匹配你家鱼的实际需求；设备只是报警，不负责控温。加热棒的原装温控仍然要保留。

### 6.3 浑浊度优先验证（建议先做）

浑浊度是整套系统里唯一需要先验证的部分。温度（DS18B20）和浮球/漏水都成熟可靠，光学方案是否可用取决于鱼缸玻璃厚度、光线环境和元件批次，所以**先用最小程序单独测通，再决定要不要接进主程序**。

配套程序：`arduino/turbidity_test/turbidity_test.ino`（只测 LED + 光敏电阻，串口打印原始值，不接 OLED 和报警）。

**准备**

- Arduino + 红色/红外 LED + 220Ω + 光敏电阻 GL5528 + 10kΩ + 面包板 + 杜邦线
- 一个透明方形玻璃杯或小玻璃盒（方形比圆形折射小），装半杯自来水或鱼缸水
- 牛奶（或少量面粉/淀粉悬浊液）当“浑水”样本
- 黑色卡纸或黑胶带做遮光筒

**接线**

```
D7 ── 220Ω ── LED 正极；LED 负极 ── GND
5V ── 光敏电阻 ── A1；A1 ── 10kΩ ── GND
```

（与主程序 D7 / A1 一致，验证通过后直接迁移。）

**步骤**

1. 上传 `turbidity_test.ino`，打开串口监视器（9600）。建议点开“工具 → 串口绘图器”看曲线，更直观。
2. 先不夹玻璃杯：看 `ambient`（环境光）和 `signal`。用手完全遮住 LED 和光敏电阻，`signal` 应掉到接近 0，说明遮光有效。
3. 把 LED 和光敏电阻用黑色遮光筒包住，夹在清水杯两侧（透射式），记录 1 分钟里 `signal` 的稳定值和波动范围。
4. 往杯里滴 1 滴牛奶并搅拌，观察 `signal`；再滴到 3–5 滴，记下每个档位的值。
5. 把水倒掉换清水，看 `signal` 是否回到第 3 步的基线（可逆性）。

**判读标准**

| 现象 | 判断 | 处理 |
|---|---|---|
| 清水 `signal` 稳定，波动 < 15%，清水 vs 3–5 滴牛奶差 > 40% | ✅ 方案可用 | 进入 6.4 第五步做正式基线 |
| 清水 `signal` < 100 | 灵敏度不足 | 缩短 LED-LDR 距离；换更亮 LED；下拉电阻 10k→5k 或 2.2k |
| `lit` 接近 1023 饱和 | 光太强/太近 | 增大 LED 串阻；拉远距离 |
| 波动 > 20% | 环境光漏入或接触不良 | 加强遮光筒；重插杜邦线；关掉直射灯 |
| 清水/浑水差异 < 1.5 倍 | 这个光学头不合适 | 换红外 LED + 光电晶体管，或改用现成浊度模块（TSW-20M / SEN0189），或放弃浑浊度只保留温度/水位/漏水 |

**决策**

- 通过 → 用主程序做正式浑浊度基线（见 6.4 第五步）。
- 不通过 → 不必纠结，浑浊度本来就只是“趋势参考”，砍掉它不影响温度、水位、漏水这三项核心功能。

> 测试只在单独的杯子里做，牛奶/面粉**绝不**滴进鱼缸。

### 6.4 校准步骤

**第一步：OLED 和温度**

1. 只接 USB、OLED 和 DS18B20，上传程序。
2. 屏幕出现 `FISH GUARD`，第 1 页显示室温。
3. 屏幕不亮：查 A4/A5，或把程序里的 `0x3C` 改成 `0x3D`。
4. 显示 `--.-` 或 `SENSOR ERROR`：查 DS18B20 三根线和 4.7kΩ 上拉。

**第二步：温度偏移**

1. 把 DS18B20 和玻璃温度计放进同一杯水，等 2 分钟。
2. 比较读数。例如设备显示 26.8°C、温度计 26.4°C，就把 `TEMP_OFFSET` 改成 `-0.4`。
3. 重新上传，确认两者差值在 ±0.3°C 内。

**第三步：浮球方向**

- 代码把 D4 读到低电平视为报警。手动抬起浮球，检查报警方向。
- 如果方向相反，翻转浮球的安装方向；若无法翻转，把 `floatClosed` 的判断改成 `HIGH` 并重新测试。

**第四步：漏水阈值**

1. 第 2 页显示 `LEAK` 原始值；干燥时应接近 0。
2. 用湿纸巾跨接两根螺丝，记下稳定后的数值，例如 450。
3. 把 `LEAK_THRESHOLD` 设为干湿之间，例如 250。
4. 测试后擦干螺丝，确认数值回到接近 0。

**第五步：浑浊度基线**

1. 把光学头固定在最终位置。
2. 擦干净鱼缸玻璃，保持正常鱼缸灯和房间灯。
3. 断电，按住按键重新上电，保持 3 秒，屏幕显示 `CAL saved`。
4. 第 2 页会显示 `CLOUD 0%` 左右；第 3 页显示基线值。
5. 如果想验证：在一只**单独的玻璃杯**里装鱼缸水，滴一小滴牛奶，把光学头夹在杯子两侧测试，观察 `CLOUD` 变化。**绝对不要把牛奶滴进鱼缸。**

## 7. 组装与上缸

### 7.1 周六上午：电源、OLED、温度

1. 在面包板上插好 Nano，USB 接入电脑。
2. 接 OLED：VCC→5V、GND→GND、SDA→A4、SCL→A5。
3. 接 DS18B20：红线 5V、黑线 GND、黄线 D2，D2 与 5V 之间接 4.7kΩ。
4. 上传程序，确认屏幕显示温度。
5. 把探头放进室温水杯，和玻璃温度计对比，记录偏差。

### 7.2 周六下午：按键、蜂鸣器、水位、漏水

1. 按键一端 D3、一端 GND；按一下确认页面能切换。
2. 蜂鸣器按接线表接好；长按按键 2 秒测试静音标志。
3. 浮球开关一端 D4、一端 GND；手动抬起测试报警方向。
4. 漏水探针：D8→螺丝 A，螺丝 B→A0，A0→10k→GND；用湿纸巾测试。
5. 把漏水探针装在小托盘上，放在鱼缸下方或管路接头下面。

### 7.3 周日：光学头、装盒、上缸

1. 把 LED 和光敏电阻装进黑色遮光筒，夹在鱼缸玻璃上。
2. 透射式装两侧；若信号太弱，改成同侧散射式并设置 `TURB_INVERT=true`。
3. 把所有电子件装进塑料盒：开 OLED 窗口、按键孔、蜂鸣器孔和出线槽。
4. 盒子放在鱼缸上方或旁边搁板上，所有线做滴水弯，探头线用吸盘固定。
5. 温度探头放在过滤出水口附近，离加热棒至少 10cm；浮球放在过滤仓或角落，加保护罩。
6. 连续运行 24 小时，每小时记录一次水温和玻璃温度计读数。

### 7.4 上缸检查清单

- [ ] OLED 正常显示，温度与玻璃温度计一致
- [ ] 按键短按翻页，长按静音
- [ ] 蜂鸣器能响，音量不吓鱼
- [ ] 冰水杯触发蓝灯/低温报警
- [ ] 温水杯触发红灯/高温报警
- [ ] 湿纸巾触发漏水报警
- [ ] 抬起浮球触发水位报警
- [ ] 浑浊度基线已保存，`CLOUD` 在 0% 附近
- [ ] 所有线有滴水弯，盒子在溅水范围外
- [ ] 连续运行 24 小时无死机、无漂移

## 10. 故障排查

| 现象 | 先查什么 | 处理 |
|---|---|---|
| OLED 全黑 | I2C 地址、A4/A5 接线、OLED 供电 | 改 0x3D；重新插线；换一块 OLED 测试 |
| 温度显示 `--.-` / `SENSOR ERROR` | DS18B20 三根线、4.7kΩ 上拉、探头是否进水损坏 | 重接；换探头；检查电缆密封 |
| 温度比温度计高/低 | 探头位置、`TEMP_OFFSET` | 远离加热棒；用杯子重新校准 |
| 蜂鸣器一直响 | 模块触发极性；报警条件是否真的成立 | 低电平触发模块要把 HIGH/LOW 对调；先看屏幕是哪种报警 |
| 浮球一直报警 | 安装方向、常开/常闭型号 | 翻转浮球或改判断条件 |
| 漏水不报警 | 阈值太高、螺丝间距太大、水太纯 | 湿纸巾实测后降低 `LEAK_THRESHOLD`；缩小间距 |
| 漏水一直报警 | 探针受潮、托盘积水、线间短路 | 擦干、抬高探针、检查焊点/杜邦线 |
| 浑浊度一直 100% | 基线错误、遮光不良、LED/光敏接反 | 重新校准；检查极性；加遮光筒 |
| 浑浊度一直 0% | 基线过高、光学头没对准、LED 不亮 | 第 3 页看基线；检查 LED；重新做基线 |
| 充电宝自动关机 | 负载电流太小 | 换“小电流模式”充电宝，或用带漏保的适配器 |
| 页面乱跳 | 按键抖动、上电时按住按键 | 加 0.1µF 去抖；上电时不要按按键 |
| 夜间蜂鸣太吵 | 报警确实发生 | 长按静音；漏水/探头故障仍会响，先排查原因 |

## 11. 安全与动物福利

1. **只使用 5V 低压。** 不要用 Arduino 控制 220V、加热棒、水泵或任何市电负载。
2. **入水部件必须密封。** 只有 DS18B20 探头和浮球开关可以进水；电缆入口保持在水面以上；发现破损立即停用。
3. **不要把裸电极放进鱼缸。** 直流电会电解水、腐蚀探针，铜离子对鱼和虾有毒。漏水探针放在缸外托盘。
4. **电源远离水。** 推荐充电宝；用适配器时选正规产品、配漏电保护，并放在高于鱼缸的位置。
5. **所有线做滴水弯。** 电子盒放在鱼缸上方或旁边的搁板上，不要放进潮湿的缸盖里。
6. **不要往鱼缸里加测试物。** 牛奶、食物等测试只在单独的杯子里做。
7. **声音和光要克制。** 蜂鸣器音量适中；浑浊度 LED 短脉冲并加遮光罩，避免夜间惊鱼。
8. **设备是辅助，不是生命保障。** 仍然要定期换水、清洗滤材、用试剂检测 pH/氨氮/亚硝酸盐，并观察鱼的行为。
9. **维护前断电。** 清洗鱼缸、移动探头时先断开 USB；不要湿手插拔。

- **数据记录**：加 microSD 模块或 ESP32 联网，把温度/浑浊度记录到手机或云端。
- **过滤监测**：霍尔流量计或振动传感器，检测水泵是否停转。
- **更稳的浑浊度**：改用红外 LED + 光电晶体管，或做 90° 散射结构，减少环境光影响。
- **pH 模块**：可以买带 BNC 的 pH 模块，但需要 pH4/pH7 校准液、探头保存液，且容易漂移；建议等孩子更大再尝试。
- **不要轻易加自动补水/自动加药**：控制出错可能把鱼缸弄坏；先做监测，熟练后再考虑闭环控制。

## 13. pH 与氨氮的配合检测

设备负责物理指标，化学指标用试剂。可以参考下面的节奏，再按你的鱼缸情况调整：

| 指标 | 参考频率 | 工具 |
|---|---|---|
| 水温 | 每天看屏幕 | 本设备 |
| pH | 每周一次 | 滴剂或试纸 |
| 氨（NH₃/NH₄⁺） | 新缸每 2–3 天；成熟缸每周或换水后 | 滴剂 |
| 亚硝酸盐 | 新缸每 2–3 天；成熟缸每周 | 滴剂 |
| 硝酸盐 | 每 1–2 周 | 滴剂 |
| 换水 | 按鱼缸密度和测试结果 | 按你的习惯 |

让孩子当“化验员”，把结果填进日报；本设备提供温度和趋势，试剂提供化学真相，两者合起来才是一套完整的水质记录。
