# 可变电阻调光 · 亲子施工文档

> 适合 6–10 岁孩子在成人陪同下完成。4.5V 电池供电，不接市电、不用电烙铁。
> 配套图：`可变电阻调光实物图.html`（面包板怎么插）

---

## 0. 一页速览

**它是什么**：拧一下旋钮，灯就从很亮慢慢变暗、再拧回来变亮。

**孩子能学到**：
- 电阻不是固定值——有一种电阻能"拧"
- 串联回路里，电阻变大 → 电流变小 → 灯变暗
- 一个真正的工程细节：**为什么必须另加一颗 220Ω 电阻**（保护）

**时间**：30–45 分钟。
**预算**：约 ¥15（电位器 ¥3–5，面包板/电池盒/跳线可复用）。

---

## 1. 原理（一句话版）

把电位器**串联**进 LED 的回路里，拧旋钮就是改电阻：

```
电阻变大 → 电流变小 → 灯变暗
电阻变小 → 电流变大 → 灯变亮
```

用公式说（孩子不用背，但要能指着图说出来）：

```
电流 I = (4.5V − LED 的 2V) ÷ (220Ω + 电位器的阻值)
```

代入具体数（红色 LED，正向压降约 2V）：

| 电位器阻值 | 回路总电阻 | 电流 | 现象 |
|---|---|---|---|
| 0 Ω（拧到底） | 220 Ω | ≈ 11.8 mA | 很亮 |
| 200 Ω | 420 Ω | ≈ 6.2 mA | 明显变暗 |
| 500 Ω | 720 Ω | ≈ 3.6 mA | 暗 |
| 1 kΩ（拧到另一端） | 1220 Ω | ≈ 2.1 mA | 很暗但还看得见 |

所以**亮度是被"电流"决定的，而电流是被"总电阻"决定的**。这就是欧姆定律最直白的一次现场演示。

## 3. 电位器是怎么回事

### 3.1 三个脚

电位器（旋转式）有 3 个脚，图上标 **A、W、B**：

- **A、B 是电阻体的两端**，它们之间的总阻值是固定的（1kΩ 就是 1kΩ）；
- **W 是中间的滑动端**，拧旋钮就是在 A 和 B 之间滑动它。

拧到最左：W 贴着 A，A–W 之间电阻 ≈ 0。
拧到最右：W 贴着 B，A–W 之间电阻 = 整个 1kΩ。

### 3.2 本图用的接法：变阻器接法

只取 **A–W 这一段**当可变电阻用，B 脚不参与主回路，但**要用一根短线把 B 和 W 连起来**。

为什么要连 B–W？两个原因：

1. 万一滑动端用久了接触不良，电流还能从 B–W 这根短线绕过去，电路不会突然断掉（只是变成最大阻值）；
2. 让 B 脚不会"悬空"，减少手上静电和干扰的影响。

### 3.3 为什么必须保留 220Ω（这条最重要）

如果**只用电位器**直接串 LED：把旋钮拧到 0Ω 的瞬间，4.5V 几乎全部压在 LED 上，电流会冲到几百 mA——LED 会瞬间烧掉，电位器也可能被烧出黑点。

加了 220Ω 之后：即使电位器拧到 0Ω，回路里也还有 220Ω 兜底，电流被限制在 11.8mA（5mm LED 的额定值是 20mA），**怎么拧都安全**。

这就是工程师常说的"限流电阻"。让孩子自己说一遍：**"220 是保险，电位器是调节。"**

## 4. 接线

### 4.1 面包板规则（一句话）

同一列的 5 个孔是通的；中间凹槽把上下两半分开，**上下不互通**；两条电源轨各自整条相通。

### 4.2 元件怎么插

都在**同一排**（图上标 J 的那一排，也就是最靠电源轨的一排）：

| 编号 | 元件 | 插在哪 |
|---|---|---|
| ① | 220Ω 电阻 | 第 7 列 ↔ 第 10 列 |
| ② | 1kΩ 电位器 | 第 14 / 15 / 16 列（依次是 **A / W / B**） |
| ③ | 红色 LED | 长脚（＋）第 **20** 列，短脚（−）第 **21** 列 |
| ④ | 3×AA 电池盒 | 红线 → ＋轨，黑线 → −轨。**先别拨开关** |

### 4.3 跳线怎么走

| 跳线 | 从 | 到 | 图上颜色 |
|---|---|---|---|
| a | 第 7 列（220Ω 左端） | ＋ 轨 | 红 |
| b | 第 10 列（220Ω 右端） | 第 14 列（电位器 A） | 橙 |
| c | 第 15 列（W） | 第 16 列（B） | 深灰（短接线） |
| d | 第 16 列（B） | 第 20 列（LED 长脚 ＋） | 橙 |
| e | 第 21 列（LED 短脚 −） | − 轨 | 蓝 |

连起来就是一条链：

```
＋轨 → 220Ω → 电位器 A ─(电阻体)─ W ─短接─ B → LED＋ → LED− → −轨
                                    ↑
                              拧旋钮就改这一段
```

## 5. 分步搭建

**第 1 步：先确认灯会亮（别急着上电位器）**
电池红线插 ＋ 轨、黑线插 − 轨；220Ω 一端接 ＋ 轨，另一端接 LED 长脚所在列；LED 短脚接 − 轨。拨开关 → **灯应该亮**。

> 这一步是"控制变量"：先证明电池、LED、电阻都没问题，后面出问题就一定在电位器那一段。这也是工程师排查故障的思路。

**第 2 步：量一下电位器**
用万用表电阻档量 A–W 两脚，一边拧旋钮一边看读数：应该从接近 0 连续变到约 1kΩ。**先确认电位器是好的**，再插进电路。

**第 3 步：把电位器串进去**
按 §4.2 / §4.3 插好，注意 W–B 那根短接线别漏。拨开关，慢慢拧旋钮。

**第 4 步：观察并记录**
让孩子拧到 5 个不同位置，每次说一句"现在比刚才亮/暗"。再问一句：**"为什么拧一点点，亮度就变很多？"**（答案见 §6）

## 6. 为什么"拧到后面就没反应了"

这是这个电路最值得讲的地方，用 1k 和 10k 会看到完全不同的现象。

电流公式是 `I = 2.5V ÷ (220 + R)`。电阻是**加在分母上**的：

- R 从 0 变到 200：分母从 220 变到 420，几乎翻倍 → 电流掉一半，**变化剧烈**；
- R 从 800 变到 1000：分母从 1020 变到 1220，只多了 20% → 电流只掉一点，**看不出差别**。

换成 10kΩ 电位器时更极端：整个旋钮 300°，其中**前 30°（1/10 行程）就走完了 80% 的变化**，剩下 270° 基本"没反应"。孩子容易以为坏了。

三个可选的处理：

1. **换 1kΩ 电位器**（本图推荐）——整段行程都有效，手感最好；
2. 保留 10kΩ，把这件事当成教学点：**"电阻越大，再加电阻的效果越小"**，这正是"边际效应"；
3. 想全程都均匀，就得用 PWM（数字调光），那是 Arduino 的活（见 §8）。

## 7. 常见问题

| 现象 | 先查什么 | 常见原因 |
|---|---|---|
| 完全不亮 | 电池开关、LED 极性 | LED 长脚（＋）要朝电位器那侧 |
| 一直最亮，拧旋钮没反应 | 电位器是不是只接了 A、B 两端 | W 脚没接进回路，等于接了个固定 1k |
| 一直不亮 | W–B 短接线漏了 / A 或 B 没插到底 | 跳线没插进孔 |
| 拧到某个角度会闪一下灭 | 电位器内部接触不良 | 廉价电位器的通病，换个角度或换一个 |
| 灯很暗，几乎看不见 | LED 颜色 | 暖白/蓝/绿在 4.5V 下本来就暗，换红色 |
| 电位器发烫 | 220Ω 是不是漏了 | **立刻断电**，检查限流电阻 |

## 8. 量一量（推荐给 8 岁以上）

用万用表直流电流档**串在回路里**（红笔接 ＋轨，黑笔接 220Ω 那端），记录：

| 旋钮位置 | 电位器阻值（Ω） | 电流（mA） | 亮度（1–5 分） |
|---|---|---|---|
| 最左 | | | |
| 1/4 | | | |
| 1/2 | | | |
| 3/4 | | | |
| 最右 | | | |

把"阻值 → 电流"画成曲线，会发现它不是一条直线，而是一条**越来越平的曲线**——这就是 `I = U/R` 里 R 在分母上的样子。孩子画完这张图，比做十道计算题印象深。

## 9. 进阶

- **比较 1k 和 10k**：同样的电路换一个电位器，看手感差别，再解释为什么；
- **加三极管**：用电位器控制基极，让三极管去带更大的电流（这就是小夜灯那个电路的思路）；
- **Arduino PWM**：`analogWrite(pin, 0~255)` 用数字方式调光，顺便解决"不均匀"的问题；
- **换成光敏电阻**：把手拧改成"光来拧"，就是自动小夜灯。
